# Contributing

Thank you for considering a contribution to this sample.

## How to contribute

1. Open an issue describing the proposed change, unless it is a security issue.
2. Keep changes focused and include validation steps.
3. Run CloudFormation linting and compile or test all inline Lambda code.
4. Update the README when behavior, parameters, costs, cleanup, or security controls change.
5. Submit a pull request with a concise description and test evidence.

By contributing, you agree that your contributions will be licensed under the MIT-0 License.

## Security issue notifications

Do not report a suspected vulnerability through a public GitHub issue. Report potential security issues through the [AWS vulnerability reporting process](https://aws.amazon.com/security/vulnerability-reporting/).

## Code of conduct

This project has adopted the [Amazon Open Source Code of Conduct](https://aws.github.io/code-of-conduct). For questions or concerns, follow the reporting instructions in that document.
